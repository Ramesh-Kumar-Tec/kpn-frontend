# KPN Chatbot Question Coverage

Use these questions after each chatbot update. The expected behavior is listed beside each group.

## Property search

- `Show apartments under 35L` → apartments with maximum budget of ₹35L.
- `Show 2 BHK apartments between 35L and 40L` → only 2 BHK apartments in that range.
- `Show 2bhk apartment price inbetween 35l to 40l` → same range handling, including “inbetween”.
- `Show apartments above 40L` → apartments with minimum budget of ₹40L.
- `Show apartments starting from 30L` → apartments from ₹30L onward.
- `Show the plots price low to high` → plot rates sorted from lowest to highest per sq.ft.
- `Show the most expensive plots` → plot rates sorted from highest to lowest per sq.ft.
- `Show the cheapest apartment` → lowest-priced apartment first.
- `Show apartments in Urapakkam` → apartments filtered by Urapakkam.
- `Show plots near Guduvanchery` → plots filtered by Guduvanchery.
- `Show 1 BHK flats` → 1 BHK apartments only.

## Inventory and project details

- `How many available units are in DGM Monica Residency?` → count only that project.
- `Which plots are available now?` → current available plot inventory.
- `Is KPN LeNid ongoing?` → exact project status.
- `Tell me about DGM Monica Residency` → project details, price, location, and brochure option.

## Actions

- `Download Monica Residency brochure` → official brochure card.
- `Open projects page` → navigation card.
- `How can I contact you?` → phone, WhatsApp, office, and contact page.
- `I want to book a site visit` → lead form.
- `What is the EMI for a 25L loan?` → EMI calculation card.

## Location and business questions

- `Which projects are near Kilambakkam?` → nearby project results.
- `Is there cab pickup?` → clear answer that KPN does not provide cab pickup/drop.
- `Are the plots DTCP and RERA approved?` → approval information and advisor option.
- `Can I get a home loan?` → loan assistance information.

## Language coverage

- `வணக்கம், வீடு வேண்டும்` → Tamil response.
- `Urapakkam la 2 BHK irukka?` → Tanglish response with relevant apartments.
